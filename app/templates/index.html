Security Tools

Open a tool to see its workspace. The dashboard talks to Flask over HTTP. Full tool forms will use that same API in a later part.

PA

Password Analyzer

Evaluate password strength based on length and character complexity. Nothing is stored in the browser.

#

Hash Calculator

Generate and compare cryptographic hashes such as SHA-256 and SHA-512. MD5 is shown only for learning.

FI

File Integrity Checker

Monitor files using SHA-256 reference hashes to detect modifications. File contents are never stored.

IP

IP Information

Inspect IP address information, network details, and address type (public, private, loopback, reserved).

LA

Log Analyzer

Analyze security logs and identify common events and potentially suspicious patterns.

About

Frontend

HTML, CSS, and JavaScript build this dashboard: layout, styling, and navigation. They do not score passwords or hash files.

Backend

Flask serves this page and JSON APIs such as /api/status. Version 1 Python modules stay separate and are called from routes, not from the browser.

Local use

Run the app on localhost. Do not put API keys or secrets in these frontend files. Educational and authorized practice only.

CyberToolkit — student learning project. Not a production security product.
